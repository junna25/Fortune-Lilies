# Fortune-Lilies

> セリフをランダムで標準してくれる、癒し?のデスクトップアプリ。

---

## 🖼️ 概要

- ランダムでセリフ・発言者・出典を表示  
- 発言者の名前でブラウザ検索可能  
- 各要素はすべてランダム  
- シンプルなワンクリック操作  

---

## 🛠️ 必要な環境

- Windows PC
- Python 3.8 以上
- ライブラリ：
  - `tkinter`（標準）
  
---

## 📦 インストールとセットアップ

1. **Python をインストール**  
   https://www.python.org/downloads/windows/  
   ※ インストール時に「Add Python to PATH」にチェックを入れてください。
